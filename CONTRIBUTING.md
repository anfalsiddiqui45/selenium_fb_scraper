# Contributing

Thank you for your interest in contributing to this project. Please follow these steps:

1. Fork the repository and create a topic branch:

   ```bash
   git checkout -b feat/my-feature
   ```

2. Write clear commit messages and keep changes focused.

3. Run tests and linters locally (if added) before submitting a pull request.

4. Open a Pull Request describing the change and why it is needed.

For major changes, please open an issue first to discuss what you would like to change.
